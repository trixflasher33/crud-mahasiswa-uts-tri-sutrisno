# Aplikasi CRUD Data Mahasiswa (Latihan UTS)

- **Nama:** Tri Sutrisno
- **Mata Kuliah:** Pemrograman Web2
- **Teknologi:** PHP (PDO), MySQL, HTML/CSS (Dark Mode)

## Cara Menjalankan
1. Buat database baru di phpMyAdmin (misal: `online_store_db`).
2. Import file `mahasiswa.sql` ke dalam database tersebut.
3. Sesuaikan pengaturan koneksi di `config.php`.
4. Jalankan melalui browser di `http://localhost/latihan_uts/index.php`.
